PeraPlano — Mobile App UI
Full-feature handoff · every screen in Light + Dark · flat screens · static mockups
Assumptions
  • Android-first: bottom tabs, system back, bottom sheets for pickers.
  • No brand SVGs attached → Lucide send glyph is the mark everywhere.
  • Sample data is Filipino-flavored: Jollibee, Meralco, GCash to “Mama”, kinsenas.
  • Soon = grey, desaturated, dormant · Plus = normal colors + green lock badge.
System
  • Inter only. Money = tabular figures, 700–800 weight, ₱ with centavos.
  • 4-pt spacing · card radius 16 · chip radius 999 · screen padding 16.
  • Green leads; PH-flag blue/red/yellow only as tiny badge details.
  • Limit bars: green → amber at 80% → red at 100%.
